# АРКА 123 — сайт

```bash
cd site
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

## Структура

- `src/components` — секции, прелоадер, лого, 3D, video-hero
- `src/shared/constants` — контент и бренд
- `public/images` — лого, галерея, реклама
- `public/video/hero.mp4` — ролик первого блока (из `materials/video_1022791.mp4`)

## Материалы

Исходники в `../materials`.
